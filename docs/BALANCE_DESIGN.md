## 2. 统一口径与公式

### 2.1 伤害口径（无减伤系统）

【推导】当前工程里**没有护甲/减伤/暴击/属性克制**。`CombatResolver` 只做四件事：同队不伤害、无敌帧拦截、最小伤害 1、致死钳到 0。因此：

```
实际伤害 = roundi(基础伤害 × attack_multiplier × target_multiplier)
         （若目标处于无敌帧 → 0，且该次攻击作废）
```

- 【断言】`roundi(12 × 1.2) = 14`、`roundi(16 × 1.2) = 19`、`roundi(24 × 1.2) = 29`（combat_rules_test:15、blessing_rules_test:34）。注意是**逐段取整**，不是整轮取整；若是整轮取整（52×1.2=62.4→62）结果就不会是 14/19/29。
- 【推导】技能**不受**烈焰之刃影响（blessing_rules_test:42 断言技能仍为 35）。

### 2.2 DPS 口径

| 口径 | 公式 | 数值 |
| --- | --- | --- |
| 连招循环 DPS | (12+16+24) / (0.48+0.56+0.72) = 52 / 1.76 | **29.545** 【模拟】L12 |
| 持续 DPS（含技能，60s 窗口） | 模拟：技能好了即放 | **31.533** 【模拟】L43 |
| 持续 DPS（只普攻） | 连招循环 | 29.667 【模拟】L43 |
| 烈焰之刃持续 DPS | 同上但普攻 ×1.2 | **36.700** 【模拟】L44 |
| 技能边际收益 | (31.533 − 29.667) | +1.866 dmg/s（+6.29%） |

口径说明【模拟】L43-46：DPS 按「动作开始时刻」计，不含命中延迟与闪避空转，因此是**上限值**。真实玩家利用率见 1.5 节的 65%/85%/100% 三档。

### 2.3 TTK 口径

```
TTK = 首次使「累计伤害 ≥ 目标生命」的命中时刻
命中时刻 = 动作开始时刻 + hit_start
```

TTK 用深度优先搜索求**最优动作序列**（0.1% 精度内可视为最优），而不是"一直无脑连招"：

| 目标 | 只普攻 TTK | 含技能最优 TTK | 提速 |
| --- | --- | --- | --- |
| 单哨兵 45HP | **1.290 s**（3 段） | **0.730 s**（`attack_01@0.16` → `skill@0.73`） | **43.41%** |
| Boss 350HP | **11.850 s** | **10.790 s**（技能 2 次，19 个动作） | 8.95% |
| Boss 350HP + 烈焰之刃 | 10.090 s | **9.030 s**（16 个动作） | — |

【模拟】L26-33、L37-40、L152。

### 2.4 生存口径

```
敌方输入 DPS_in = Σ(单次伤害 / 出手周期)
无敌覆盖率 U    = (无敌结束 − 无敌开始) / 闪避冷却
受击概率 p_hit  = 1 − 闪避成功率（与 U 正相关，且受"同时出手的敌人数"压制）
预期损失 HP     ≈ DPS_in × p_hit × 房间时长
相对安全裕度    = 清场剩余 HP / 生命上限
```

关键推导【推导】：

- 哨兵出手周期 = max(动作 1.28s, 冷却 1.30s) = **1.30s**（主口径）或 1.28+1.30 = **2.58s**（宽松口径）。**两种口径使 3 哨兵房威胁相差 1.78x**（36.2 vs 20.4 HP，【模拟】L126-127）。这属于规则口径不明，不是数值问题，必须由研发确认 `attack_cooldown` 的计时起点后本文结论才闭环。
- Boss 出手密度 = 招式时长 + 间隔，横扫 1.67+U(1.6,2.4) ≈ 3.67s 一次；因此 **34.5 秒内只会出手约 9 次**，而当前战斗只有 14.22s。
- 无敌覆盖率 16.67% 意味着**即使玩家完美操作，理论上也只能免掉约 1/6 的伤害时间覆盖**；面对 3 个相位错开的哨兵（每 0.43s 一次出手）时闪避冷却成为硬约束 → 【模拟】3 哨兵房闪避成功率 39.2%，单哨兵/2 哨兵房 47.2%。

### 2.5 阈值口径（本次发现的关键公式）

```
哨兵击杀段数 n  = min{ n : Σ_{i=1..n} roundi(dmg_i × mult) ≥ 哨兵生命 }
```

| 场景 | 前 2 段累计 | 前 3 段累计 | 击杀段数 |
| --- | --- | --- | --- |
| ×1.00 | 12+16 = **28** | +24 = **52** | **3** |
| ×1.20 | 14+19 = **33** | +29 = **62** | **3** |

【推导】只要哨兵生命落在 (28, 52] 区间内，**任何普攻加成都会被"3 段"这个整数阈值吃掉**。要让 ×1.2 产生段数差，需 `哨兵生命 ≤ 33`；要让 ×1.2 减一段，等价于要求 `2 段 × 1.2 ≥ 哨兵生命`。反过来，把哨兵生命提到 **56**，则基线需 4 段（1.92s）、烈焰之刃 3 段（1.29s）→ 增益 32.8%。**这是"调整哨兵生命"而不是"调整烈焰之刃倍率"的根本原因。**

### P1-1 全流程没有致死压力（最严重）

| 证据 | 数值 | 出处 |

| 普通玩家 2 哨兵房阵亡率 | 0.0% | 【模拟】L52 |

| 普通玩家 Boss 房阵亡率 | 0.0% | 【模拟】L68 |
| 新手 Boss 房阵亡率 | 0.0% | 【模拟】L120 |
| **完全不闪避** Boss 房损失 HP | 54.1 / 100，阵亡率仍 0.0% | 【模拟】L72、L206 |
| Boss 战平均出手次数 | **2.99 次** | 【模拟】L168 |
| Boss 战平均时长 | 14.22 s | 【模拟】L167 |

结论【模拟】：**即使玩家一次闪避都不用，也打不死玩家**。原因是 Boss 350HP 对玩家 31.5 DPS 只有 10.79s 的 TTK，Boss 在 14.22s 内总共只出手 2.99 次、每次 20/25 伤害，理论上限伤害约 65~75，达不到 100 HP 血池。**这不是"玩家太强"，而是"Boss 血量相对玩家 DPS 太低"**——招式循环根本无法展开。

### P1-2 三个祝福强度严重失衡

| 祝福 | 哨兵 TTK 增益 | Boss TTK 增益 | 2 哨兵生存增益 | 3 哨兵生存增益 | Boss 生存增益 | **综合均值** |
| --- | --- | --- | --- | --- | --- | --- |
| 烈焰之刃 | 0.00% | 16.31% | 85.76% | 44.30% | 28.64% | **35.00%** |
| 生命共鸣 | 0.00% | 0.00% | 43.67% | 27.60% | 0.00% | **14.25%** |
| 疾风步伐 | 0.00% | 0.00% | −0.79% | 5.15% | 0.00% | **0.87%** |

【模拟】L79-81（TTK）、L85-88（生存）、L92-94（综合）。

**差距 40 倍**（35.00% vs 0.87%）。注意烈焰之刃 85.76% 的 2 哨兵增益带有"刀口效应"成分（见 3.6），稳健区间是 3 哨兵 44.30% 与 Boss 28.64%；即便如此仍远高于另两个。

### P1-3 烈焰之刃在哨兵房完全无效 → 第一个祝福的体验是"空卡"

- 【模拟】单哨兵 TTK 在 ×1.00 与 ×1.20 下都是 1.290s（L26 vs L28），增益 **0.00%**。
- 【推导】原因见 2.5 节的整数阈值：45 HP 在两种倍率下都需要 3 段。
- 玩家第一次选卡发生在**房 1 之后、房 2 之前**。也就是说：**玩家拿到的第一张卡，在接下来的整场战斗里几乎完全感知不到**（房 2 的 3 个哨兵也是 3 段击杀）。这是"祝福系统看起来有得选、实际上没得选"的根因。

### P1-4 疾风步伐近乎无效（闪避冷却不是约束条件）

| 场景 | 闪避成功率（基线 1.2s CD） | 闪避成功率（疾风 0.9s CD） | 损失 HP 变化 |
| --- | --- | --- | --- |
| 2 哨兵 | 47.2% | 46.7% | 10.5 → 10.6（**−0.79%**，反而更差） |
| 3 哨兵 | 39.2% | 48.0% | 36.2 → 34.4（+5.15%） |
| Boss | 77.4% | 77.4% | 14.6 → 14.6（**0.00%**） |

【模拟】L52-55、L60-63、L68-71、L88。

原因【推导】：
1. 无敌覆盖率只从 16.67% 涨到 22.22%（+33% 相对值），但**绝对增量只有 5.5 个百分点**；
2. Boss 出手间隔约 3.67s，远大于 1.2s CD → **CD 根本不是瓶颈**，改 CD 对 Boss 房毫无意义；
3. 只有 3 个哨兵相位错开、0.43s 一次出手时 CD 才成为约束（该场景 +5.15%）；
4. 2 哨兵房出现负增益是因为"多闪一次 = 多 0.45s 空转 = 少输出"，在稀疏攻击下**闪避的位移成本大于收益**。

### P1-5 生命共鸣的 +20 上限是无效属性，实际收益全部来自击杀回血

## 8. 结论摘要（一页版）

1. 【模拟】当前数值下**全流程无法致死**：普通玩家三个房间阵亡率均为 0.0%，即使完全不闪避也打不死（Boss 房损失 54.1/100）。根因是 Boss 350HP 对 31.5 DPS 只有 10.79s TTK，Boss 在 14.22s 里只出手 2.99 次。
2. 【模拟】祝福强度极差 **34.13 个百分点**（烈焰 35.00% / 生命 14.25% / 疾风 0.87%），最优策略恒为"选烈焰"。
3. 【推导】烈焰之刃在哨兵房增益 **0.00%** 是**整数段数阈值**造成的（45HP 在 ×1.0 与 ×1.2 下都需 3 段），因此"提高烈焰倍率"是无效修法，"把哨兵血量提到 56"才是正解（段数差 4→3）。
